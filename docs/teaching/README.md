# wife-system 阶段 0～3 实现后教材

这套教材以固定提交 `6e897623ba598d0f8f26ba1ad694dafcae0cf103` 为代码基线。它面向会 Python 和基础 Git、正在补齐后端、数据库与 Agent 工程知识的学习者。旧教学资料只是参考输入；本套内容按最终代码、冻结接口和最终验收报告重新核对。

## 推荐顺序

| 顺序 | 教材 | 建议单元 | 学完后能说明 |
|---|---|---:|---|
| 1 | [P0：最小 Agent、HTTP 与微信桥接](p0-agent-http-wechat.md) | 4 | 模型、工具、FastAPI 与 OpenClaw 怎样协作 |
| 2 | [P1：财务数据底座](p1-finance-data-foundation.md) | 5 | 账本、事务、幂等和双数据库门禁 |
| 3 | [P2：财务 Agent 工作流](p2-finance-agent-workflow.md) | 5 | 自然语言怎样安全地变成一次待确认财务写入 |
| 4 | [P3：Markdown 活动导入](p3-activity-import.md) | 6 | 确定性解析、预览确认、并发与原子提交 |

建议一次只学一个单元：先画数据流，再打开所列代码，最后完成练习。测试通过代表对应案例取得证据，不等于实现对所有输入和环境都绝对正确。

## 证据标签

- **当前实现**：提交 `6e89762` 中可读到的代码行为。
- **冻结要求**：阶段接口文档规定的边界。
- **测试证据**：报告中实际执行并通过的范围。
- **未来规划**：后续阶段可用的接口或方向，尚未实现时会明确标注。

所有示例均为虚拟数据。教材不包含 API key、账号标识、微信标识或真实个人财务信息。
